MediLog API Endpoints
Base URL: http://localhost:8080
API prefix: /api/v1

Full documentation: docs/HTTP_API.md

Access levels:
- Public: no Authorization header required.
- Auth: requires Authorization: Bearer <access_token>.
- Full app: requires Authorization and completed onboarding.

Optional client metadata headers:
- X-Device-ID
- X-Device-Name
- X-Device-Fingerprint

- GET /metrics [Public]

  -H "Content-Type: application/json" \
  -H "X-Device-ID: ios-device-001" \
  -H "X-Device-Name: iPhone 15" \
  -H "X-Device-Fingerprint: demo-fingerprint" \
  -d '{
    "email": "victor@example.com",
    "password": "Password123!"
  }'
