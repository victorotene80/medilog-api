MediLog API Responses
Base URL: http://localhost:8080
API prefix: /api/v1

Full documentation: docs/HTTP_API.md

Response envelope:
{
  "status": true,
  "code": "MACHINE_READABLE_CODE",
  "message": "Human readable message",
  "data": {}
}

Error envelope:
{
  "status": false,
  "code": "MACHINE_READABLE_ERROR_CODE",
  "message": "Human readable message",
  "errors": "optional details"
}

Notes:
- Success responses include data when the handler passes response data.
- Empty success responses usually return "data": {}.
- Error responses omit data.
- Timestamps are RFC3339 strings.
- /health is plain text and returns "ok".

Common errors:
- 400 INVALID_REQUEST_BODY
- 400 VALIDATION_ERROR
- 400 INVALID_ID
- 400 INVALID_CATEGORY
- 400 INVALID_DATE
- 400 INVALID_DATE_RANGE
- 401 UNAUTHORIZED
- 401 UNAUTHENTICATED
- 403 VERIFICATION_REQUIRED
- 403 ONBOARDING_REQUIRED
- 403 ACCOUNT_NOT_ALLOWED
- 404 *_NOT_FOUND
- 422 OTP_REQUEST_FAILED
- 422 OTP_VERIFY_FAILED
- 422 ONBOARDING_OTP_VERIFY_FAILED
- 429 RATE_LIMIT_EXCEEDED
- 500 INTERNAL_SERVER_ERROR
